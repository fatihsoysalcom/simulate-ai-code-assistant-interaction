# Simulate AI Code Assistant Interaction

This example demonstrates the core interaction concept with AI code assistants like Claude or Codex. It simulates providing a natural language prompt and receiving a code snippet in response, highlighting the importance of clear and specific prompts. This interaction pattern is central to using AI assistants effectively, even from a mobile device.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py "Python hello world program"`
3. Try different prompts: `python main.py "JavaScript function for sum of two numbers"` or `python main.py "Python function to read content from a file"`
